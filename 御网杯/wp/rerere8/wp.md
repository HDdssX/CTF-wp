# rerere WP

## 题目信息

- 题目类型：Reverse
- 题目文件：`rerere.exe`
- 最终 flag：`flag{557050ec8cf8f479b22ad0797f69fe3e}`

## 分析过程

先对程序做基础观察，运行后只有一个很简单的交互：

```text
Input:
```

输入任意内容后，程序会输出 `Correct!` 或 `Wrong!`，说明这是一个本地校验型逆向题。

继续看字符串，可以发现比较关键的内容只有：

```text
Input:
Correct!
Wrong!
```

这说明核心逻辑大概率就是：

1. 读入一段字符串
2. 做逐字节变换
3. 和内置目标值比较

## 核心校验逻辑

逆到关键函数后，可以还原出如下逻辑：

```c
for (i = 0; i < len; i++) {
    x = input[i] ^ key[i & 7];
    if (table[x] != target[i]) {
        return 0;
    }
}
return 1;
```

也就是说程序用了三张表：

- `key`：8 字节循环异或密钥
- `table`：256 字节替代表
- `target`：目标比较序列

其中关键数据如下。

### 1. key

```text
[185, 205, 206, 48, 184, 97, 78, 170]
```

### 2. target

```text
[163, 91, 76, 10, 14, 184, 244, 218, 20, 117, 2, 58, 141, 229, 119, 213, 177, 67, 172, 167, 177, 73, 165, 100, 215, 150, 2, 167, 177, 121, 66, 182, 83, 67, 67, 73, 92, 108]
```

程序对长度也做了限制：

- 读取缓冲区长度是 `0x40`
- 末尾如果有换行会去掉
- 校验长度必须是 `0x26`，也就是 `38` 字节

## 逆向求解

因为校验关系是：

```text
table[input[i] ^ key[i & 7]] = target[i]
```

所以只要先把 `table` 反过来，得到：

```text
input[i] = inverse_table[target[i]] ^ key[i & 7]
```

逐字节逆回去后，得到明文：

```text
flag{557050ec8cf8f479b22ad0797f69fe3e}
```
