# ezSM4

## 结论

程序真正校验的是 16 字节原始输入，不是直接输入 `flag{...}`。

- 正确输入：`SENSOREDS4Little`
- 最终 flag：`flag{SENSOREDS4Little}`

## 题目行为

先直接运行程序看交互：

```powershell
"12345678abcdefgh" | .\ezSM4.exe
```

输出是：

```text
Wrong Answer.
```

再试长度不对的输入：

```powershell
"flag{a}" | .\ezSM4.exe
```

输出：

```text
Wrong length.
```

说明程序实际要求的是一个固定长度输入。字符串里还能看到提示：

```text
format: flag{xxx}, xxx is your input.
```

所以真正要找的是 `xxx`，最后再包成 `flag{xxx}`。

## 静态分析

在主逻辑附近可以看到几个关键点：

1. `0x140001a27` 从 `.rdata` 取出 16 字节常量：

```text
1400054e0 31323334 35363738 61626364 65666768
```

也就是：

```text
12345678abcdefgh
```

这就是固定 key。

2. `0x140001b30` 到 `0x140001b45` 写入了 16 字节目标密文：

```text
4a 5e 46 35 96 08 e9 30 da 28 ca a0 22 a6 59 4d
```

即：

```text
4a5e46359608e930da28caa022a6594d
```

3. `0x1400022d8` 附近能看到 SM4 的 `FK`、`CK` 和 SBox 常量，说明核心就是标准 SM4。

## 关键坑点

这题不是标准教科书里那种“大端装载 4 个 32 位字”的实现。

程序把 16 字节输入按下面这种方式拆成 4 个 `uint32`：

```python
int.from_bytes(block[i:i+4], "little")
```

如果直接拿常规 SM4 大端实现去解，会得到错误结果。这个 little-endian 细节是这题最容易踩坑的地方。

## 还原思路

已知：

- key = `12345678abcdefgh`
- ciphertext = `4a5e46359608e930da28caa022a6594d`

因为程序是“固定 key 加密用户输入后比对密文”，所以直接按题目的字节序把密文做一次 SM4 解密即可。

下面是可直接复现的 Python 脚本：

```python
def rol32(x, n):
    n &= 31
    return ((x << n) & 0xffffffff) | (x >> (32 - n))

SBOX = [
    0xd6,0x90,0xe9,0xfe,0xcc,0xe1,0x3d,0xb7,0x16,0xb6,0x14,0xc2,0x28,0xfb,0x2c,0x05,

FK = [0xa3b1bac6, 0x56aa3350, 0x677d9197, 0xb27022dc]
CK = [
    0x00070e15,0x1c232a31,0x383f464d,0x545b6269,0x70777e85,0x8c939aa1,0xa8afb6bd,0xc4cbd2d9,
    0xe0e7eef5,0xfc030a11,0x181f262d,0x343b4249,0x50575e65,0x6c737a81,0x888f969d,0xa4abb2b9,
    0xc0c7ced5,0xdce3eaf1,0xf8ff060d,0x141b2229,0x30373e45,0x4c535a61,0x686f767d,0x848b9299,
    0xa0a7aeb5,0xbcc3cad1,0xd8dfe6ed,0xf4fb0209,0x10171e25,0x2c333a41,0x484f565d,0x646b7279,
]

def tau(x):
    return (
        (SBOX[(x >> 24) & 0xff] << 24) |
        (SBOX[(x >> 16) & 0xff] << 16) |
        (SBOX[(x >> 8) & 0xff] << 8) |
        SBOX[x & 0xff]
    )

def l_key(x):
    return x ^ rol32(x, 13) ^ rol32(x, 23)

def l_enc(x):
    return x ^ rol32(x, 2) ^ rol32(x, 10) ^ rol32(x, 18) ^ rol32(x, 24)

def pack_le_words(block):
    return [int.from_bytes(block[i:i + 4], "little") for i in range(0, len(block), 4)]

def unpack_le_words(words):
    return b"".join(x.to_bytes(4, "little") for x in words)

def expand_key(key):
    mk = pack_le_words(key)
    K = [mk[i] ^ FK[i] for i in range(4)]
    rk = []
    for i in range(32):
        t = K[i + 1] ^ K[i + 2] ^ K[i + 3] ^ CK[i]
        t = tau(t)
        val = K[i] ^ l_key(t)
        K.append(val)
        rk.append(val)
    return rk

def crypt_block(block, rk):
    X = pack_le_words(block)
    for i in range(32):
        t = X[(i + 1) % 4] ^ X[(i + 2) % 4] ^ X[(i + 3) % 4] ^ rk[i]
        t = tau(t)
        X[i % 4] ^= l_enc(t)
    return unpack_le_words([X[3], X[2], X[1], X[0]])

key = b"12345678abcdefgh"
ct = bytes.fromhex("4a5e46359608e930da28caa022a6594d")
rk = expand_key(key)
pt = crypt_block(ct, rk[::-1])

print(pt)
print("flag{" + pt.decode() + "}")
```

```text
b'SENSOREDS4Little'
flag{SENSOREDS4Little}
```
